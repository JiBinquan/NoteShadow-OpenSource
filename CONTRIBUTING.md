# 参与贡献 / Contributing

[English](#english) · [项目首页](README.md)

感谢你改进墨鱼笔记。当前项目仍处于公开发布准备和设备验证阶段。请先查看[路线图](docs/ROADMAP.md)和已有 Issue，再提出功能或修复建议。

1. 从 `develop` 创建功能或修复分支，保持改动聚焦。
2. 按[编码规范](docs/engineering/CODING_STANDARDS.md)和[测试文档](docs/engineering/TESTING.md)工作。行为变化应有相应测试或明确的真机验证步骤。
3. 提交 PR 时说明用户可见变化、验证结果、设备/系统版本和剩余风险。提交消息使用 Conventional Commits，如 `fix: ...`。
4. 不要提交真实录音、笔记、阅读文档、API Key、签名材料、APK、构建输出或日志；公开截图请使用演示数据。

目前的第三方模型授权仍在核查中。新增模型、字体、图片或其他素材时，请同时给出来源、许可证和再分发依据。安全问题请按 [SECURITY.md](SECURITY.md) 处理。

## English

[中文](#参与贡献--contributing) · [Project home](README.en.md)

NoteShadow is preparing for its first public release and still needs device validation. Check the [roadmap](docs/ROADMAP.md) and existing issues before proposing a feature or fix.

1. Branch from `develop` and keep the change focused.
2. Follow the [coding standards](docs/engineering/CODING_STANDARDS.md) and [testing guide](docs/engineering/TESTING.md). Cover behavior changes with relevant tests or clear device validation steps.
3. In a pull request, describe user-visible behavior, verification, device/Android version, and remaining risks. Use Conventional Commits such as `fix: ...`.
4. Never commit real recordings, notes, reading documents, API keys, signing material, APKs, build output, or logs. Use demonstration data in screenshots.

Third-party model rights are still being checked. New models, fonts, images, or other assets need a source, license, and redistribution basis. Report security issues through [SECURITY.md](SECURITY.md).
