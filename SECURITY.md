# 安全漏洞报告 / Security reporting

[English](#english)

请通过仓库 **Security → Report a vulnerability** 提交私密漏洞报告，并提供受影响版本、复现步骤、预期与实际结果。不要在公开 Issue、PR 或截图中披露利用细节、真实录音、笔记或凭据。

GitHub 的私密漏洞报告需要仓库公开后由管理员在 **Settings → Advanced Security → Private vulnerability reporting** 启用。在该入口启用前，请不要把敏感漏洞细节发布到公开讨论区。普通功能问题请使用 [Issues](https://github.com/JiBinquan/NoteShadow-OpenSource/issues)。

当前 `0.5.0` 仍是发布候选版；维护者会在确认影响与修复后，通过 GitHub Security Advisory 协调披露。

## English

[中文](#安全漏洞报告--security-reporting)

Use **Security → Report a vulnerability** to submit a private report with the affected version, reproduction steps, and expected versus actual behavior. Do not post exploit details, real recordings, notes, or credentials in a public issue, pull request, or screenshot.

GitHub private vulnerability reporting must be enabled by an administrator under **Settings → Advanced Security** after the repository becomes public. Until that form is available, do not disclose sensitive vulnerability details in public discussions. Use [Issues](https://github.com/JiBinquan/NoteShadow-OpenSource/issues) for ordinary bugs and feature requests.

Version `0.5.0` is still a release candidate. The maintainer will coordinate disclosure through a GitHub Security Advisory after assessing and fixing a report.
