# 墨鱼笔记使用说明

[English](USER_GUIDE.en.md) · [返回首页](../README.md) · [隐私与数据说明](../PRIVACY.md)

![墨鱼笔记横幅](assets/readme/banner.png)

这份说明适用于 **0.5.1 预览版**。墨鱼笔记主要面向 Android 平板横屏使用，可在设备上录音、离线转写、写课程笔记、阅读 TXT/EPUB 资料并整理课程记录。界面目前为中文；下文英文版是使用说明的翻译。

> **先看这里**：当前预览版尚未完成实体设备回归测试。重要课程请同时保留原始录音并及时导出。应用最低支持 Android 6.0；随包语音识别原生库面向 ARM64 设备。

## 1. 安装与首次准备

1. 从 [v0.5.1 发布页](https://github.com/JiBinquan/NoteShadow-OpenSource/releases/tag/v0.5.1)下载一个 APK。`full` 约 1 GB，包含 Qwen3-ASR、Zipformer、SenseVoice 和 Silero VAD；`lite` 约 24 MB，不包含模型。
2. 在 Android 上安装 APK。升级旧版时使用相同签名的发布包直接覆盖安装，**不要先卸载**，否则应用专属数据会被清除。发布页提供 SHA-256 和签名证书指纹供核对。
3. 首次录音或实时转写时，按系统提示授予麦克风及通知等所需权限。录音和转写运行时会显示前台服务通知。
4. 若使用 `full`，首次启动 Qwen3 转写时，应用会将约 1 GB 模型复制到应用专属目录，请预留额外空间并等待加载完成。已有完整的 Qwen3 模型会保留。若使用 `lite` 或自行构建的无模型 APK，先按[模型文件](#11-模型文件与常见问题)准备所需模型。

录音、普通笔记、阅读和课程记录管理不要求联网或登录。可选的模型问答需要自行配置 HTTPS 接口和 API Key。

## 2. 主界面速览

![实时转写界面](assets/readme/live-transcription.jpg)

| 入口 | 用途 |
| --- | --- |
| 左侧「实时转写」「笔记」 | 切换实时转写页与课程笔记页。重新打开应用或从后台恢复时，默认显示实时转写安全页。 |
| 顶部「单线输出」「双线输出」 | 切换实时转写的显示方式。双线视图可临时混排阅读资料；正式转写文本独立保存。 |
| 顶部「记录」 | 查看项目、历史课程、归档和回收站，并导出资料。 |
| 顶部「新课」 | 结束当前课程并开始新课程。操作前会确认；旧课保存在记录中。 |
| 顶部「更多」 | 打开「进度」资料管理，或导出当前转写预览。 |
| 顶部「设置」 | 选择识别方式、屏幕常亮、可选模型接口并查看存储位置。 |
| 底部「录音」「转写」「文件转」 | 分别控制录音、实时转写和已有音频文件的离线转写。录音与转写是独立开关。 |

顶部操作区可横向滚动。点击页面标题可在当前页面与实时转写安全页之间快速切换；硬件键盘也可使用 **F8**、**Alt+Enter** 或 **Ctrl+Shift+B**。这只是显示切换，不会加密或删除内容。

## 3. 录音与实时转写

1. 在「设置」中选择实时识别方式。默认是「实时草稿 + Qwen」。识别正在运行时，先停止再切换方式。
2. 点「录音」开始保存 AAC/M4A 录音；再点一次停止。长按「录音」可打开最近完成的公开录音。只录音也可以，不必开启转写。
3. 点「转写」开始设备端实时识别；再点「停转写」结束。只转写也可以，不必同时录音。首次加载模型可能需要等待。
4. 识别结果在实时转写页显示；正式转写按时间戳保存。要修改正式转写，先停止实时转写，在双线输出页点「编辑」，修改后点「完成」。
5. 一节课结束后点「新课」。当前录音和转写会停止，现有课程被保存；新课开始时清空当前转写和笔记。

| 设置中的方式 | 所需模型 | 结果 |
| --- | --- | --- |
| 仅 Qwen，省电 | Qwen3-ASR、Silero VAD | Qwen 生成正式转写，不加载 Zipformer 草稿。 |
| 实时草稿 + Qwen（默认） | Zipformer、Qwen3-ASR、Silero VAD | Zipformer 提供即时草稿，Qwen 生成正式转写；草稿不会覆盖正式转写。 |
| 兼容模式（SenseVoice） | SenseVoice、Silero VAD | 使用 SenseVoice 的兼容识别路径。 |

「单线输出」适合只看转写；「双线输出」可将当前阅读资料的文字临时混入显示。阅读文字不会写入正式转写，也不会出现在正式转写导出中。使用这些功能前，请确认录音和识别符合你所在场所的要求。

## 4. 转写已有录音文件

1. 在 Android 10 或更高版本上，先停止实时录音和转写，点底部「文件转」，从系统文件选择器选一份设备可解码的音频文件。此功能使用 Qwen3-ASR，不依赖实时识别方式的设置。
2. 应用显示「文件转写预览」，逐段写入带时间标记的结果。点「暂停文件」可暂停；再次进入可选「继续当前」「选择其他文件」或「从头重转」。从头重转会创建新输出，旧输出保留。
3. 文件转写结果保存在公共 `Download/NoteShadow`。可通过「更多 → 导出当前转写」另存当前预览文本。文件选择器对音频格式的支持还取决于设备解码器。

## 5. 课程笔记、图片与 Markdown

![课程笔记编辑界面](assets/readme/note-editor.jpg)

点左侧「笔记」进入当前课程的手动笔记。新输入的行会自动带时间戳；笔记与录音、转写可同时进行，切换页面不会结束后台工作。正文使用 Markdown：可以写标题、列表、待办项、引用、分隔线、强调、删除线、代码、链接和表格。

- 点「拍照」或「图片」把照片或现有图片加入当前课程笔记；图片以相对路径插入 Markdown，保存在该课程的专属附件目录。
- 点「预览」查看只读的 Markdown 渲染结果，再点「编辑」返回源文本。预览包括图片、表格和代码块。
- 在笔记中独占一行输入 `/arc` 并按回车，会插入最近 **5** 条正式转写；`/arc 12` 可指定 1–200 条。它只读取当前课程的正式转写，不读取草稿、阅读内容或网络模型。

![Markdown 预览界面](assets/readme/markdown-preview.jpg)

## 6. 可选的在线模型问答

此功能与设备端语音识别分开。先在「设置 → 笔记问答 / 模型接口（OpenAI 兼容）」导入密钥文件或粘贴 Key，填写 HTTPS 接口地址、模型 ID 和需要的参数，点「保存模型接口」。如果新接口支持 `/models`，可以点「发现模型」；「测试模型连接」只发送固定短测试句。设置页还可清除密钥和查看不含问题正文的诊断记录。

在**课程笔记编辑页**输入完整命令行并按回车：

| 命令 | 用法 |
| --- | --- |
| `/lm 你的问题` | 向已配置的模型接口发送单条问题；`/ds 你的问题` 是兼容别名。 |
| `/lmlbg` … `/lmled` | 开始多行提问；在结束行提交中间输入的内容。 |
| `/lmcl` … `///` | 开始连续对话；期间每个普通非空笔记行会作为问题发送，输入 `///` 结束。 |
| `/lmnew` | 清空当前课程的模型对话上下文并开始新对话。 |

应用只在这些明确操作时向所选服务发送问题，以及**同一课程此前成功的模型问答**。它不会自动发送录音、转写、阅读文档或其他笔记行。服务提供方如何处理收到的内容，取决于你选择的服务；敏感信息请勿放进提问。新课也会重置模型对话上下文。

## 7. TXT/EPUB 资料与阅读进度

1. 点「更多 → 进度 → 添加 TXT / EPUB」，选择本机文件导入资料库。每份资料独立保存阅读进度。
2. 在资料卡片点「设为当前」；可点「设置进度」输入百分比或字符位置。EPUB 有多个章节时，还可点「选择章节」，列表会显示章节开头预览。
3. 当前资料可用于双线输出的临时文字混排，也可用于笔记页的假装输入：在笔记中独占一行输入 `/novst` 并按回车，之后输入的英文字母键会按当前资料内容推进；空格、回车和其他字符保持普通输入行为。输入 `///` 结束。先选好资料并检查进度，避免把不需要的文字插入笔记。

资料内容和阅读进度保存在设备上。资料文字不会加入正式转写导出；假装输入若写进手动笔记，则属于该笔记内容，导出笔记包时会随笔记导出。

## 8. 课程记录、项目与回收站

![课程记录详情](assets/readme/record-detail.jpg)

- 点「记录」查看课程列表；「项目」可切换、新建或重命名项目。搜索框按转写内容查找。使用归档切换按钮分别查看普通与已归档记录。
- 点某条记录查看正式转写、草稿、课程笔记和录音。可修改标题、播放录音、归档或恢复。正在录音或实时转写时，部分整理操作需要先停止工作。
- 点「移入回收站」会把该课程的应用内数据移入可恢复区域。回收站里可「恢复到原项目」，恢复原标题及归档状态；「永久删除」需要两次确认。
- 在记录页点「选择导出」可批量选择多条课程，再选转写包、笔记包或完整课程包。

**永久删除只影响应用内那条记录。** 已导出文件以及 Android 10 及以上生成的 `Music/NoteShadow` 公共录音副本不会自动删除，须自行检查文件管理器。

## 9. 导出与文件位置

| 操作 | 内容 |
| --- | --- |
| 「更多 → 导出当前转写」 | 在 Android 10 及以上，将当前显示的实时转写或文件转写预览文本导出为 TXT。 |
| 记录详情「导出正式转写」 | 该课程的正式转写 TXT。 |
| 「导出笔记包」 | 课程 Markdown 笔记及其图片组成的 ZIP，不含录音。 |
| 「导出完整课程包」 | ZIP 中可包含正式与草稿转写、Markdown 笔记、图片、录音和不含敏感内容的清单。 |
| 记录页批量导出 | 对选中的多条记录生成相应的转写包、笔记包或完整课程包。 |

Android 10 及以上的手动导出通常写入公共 `Download/NoteShadow`；完成的录音另有公共 `Music/NoteShadow` 副本。较旧系统的导出使用系统保存选择器，且不创建固定目录的公共录音副本。「设置 → 存储与目录」显示当前位置、占用与快捷查看入口；该页目前只查看，不移动文件。应用专属数据在卸载时会移除，卸载前请导出需要保留的课程。详细行为见[隐私与数据说明](../PRIVACY.md)。

## 10. 设置与日常检查

- **识别方式**：在「设置」选择三种实时模式；识别进行中不可切换。
- **屏幕常亮**：默认在录音或识别时保持屏幕常亮；关闭后允许屏幕自动熄灭，但不会因该开关停止后台工作。
- **模型接口**：仅用于显式的在线问答；可设置 HTTPS 地址、Key、模型 ID、输出长度、thinking 参数和超时，发现模型或测试连接。
- **本机数据 / 存储与目录**：查看课程数据占用、默认位置与公共文件入口。
- **应用信息**：查看当前版本号。

## 11. 模型文件与常见问题

`full` 已包含以下模型；`lite`、公开源码构建或缺少模型的安装，需要自行取得有权使用的兼容文件，并放到设备应用专属目录 `Android/data/com.noteshadow.app3/files/models/` 下。Android 文件管理器对 `Android/data` 的访问方式因系统版本和厂商而异。

| 子目录 | 必要文件 | 用途 |
| --- | --- | --- |
| `qwen3-int8/` | `conv_frontend.onnx`、`encoder.int8.onnx`、`decoder.int8.onnx`、`tokenizer/vocab.json`、`tokenizer/merges.txt`、`tokenizer/tokenizer_config.json` | 正式实时转写及文件转写。 |
| `zipformer-int8/` | `model.int8.onnx`、`tokens.txt` | 实时草稿。 |
| `sensevoice-int8/` | `sensevoice.int8.onnx`、`tokens.txt` | 兼容模式。 |
| `silero-vad/` | `silero_vad.onnx` | 实时语音分段。 |

- **转写无法启动**：检查所选模式对应的模型、文件名、剩余空间与麦克风权限。`full` 首次使用 Qwen3 需要额外复制空间；`lite` 没有预装模型。
- **安装提示签名不兼容**：确认下载的是同一应用 ID、同一签名的发布 APK。不要以卸载旧版作为首选处理方式；卸载会清除应用专属数据。
- **找不到已删除录音**：查看 `Music/NoteShadow` 公共副本和 `Download/NoteShadow` 已导出文件；它们不随记录删除。
- **模型问答失败**：检查 HTTPS 地址、Key、模型 ID 和网络连接；设置页可测试连接并查看诊断类别。
- **文件转写无法继续**：确认原始音频仍可由系统文件选择器访问，必要时重新选择文件。

如遇可重复的问题，请在 [Issues](https://github.com/JiBinquan/NoteShadow-OpenSource/issues) 提供设备型号、Android 版本、应用版本和复现步骤；不要上传真实录音、课程笔记或 API Key。安全问题请按[安全报告说明](../SECURITY.md)走私密渠道。
